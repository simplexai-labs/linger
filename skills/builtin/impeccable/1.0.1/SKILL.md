# Impeccable

Ship production-grade product UI that matches the current Linger surfaces. Do not invent a second visual system.

## Follow the product

Reuse existing Tailwind tokens, local components, and `lucide-react`. Keep light, dense, task-first layout. Use the product accent for primary actions and selection, not decoration.

## Hierarchy and type

Use weight and size, not extra colors, to show importance. Body text must stay readable against its surface. Labels stay short. No all-caps body copy. No gradient text.

## States

Every control needs default, hover, focus, disabled, loading, and error. Empty states should explain the next action. Errors name the failure and what to do.

## Interaction

Prefer inline editing, rows, dialogs, and toolbars already used in the product. Do not add a UI library. Motion is 150-250ms and only to show state change.

## Copy

Button labels are verb plus object. No marketing adjectives. No em dashes. Placeholder text must remain readable.
