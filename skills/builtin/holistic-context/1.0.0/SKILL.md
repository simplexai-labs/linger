# Holistic context

1. Start from what is already here: memory.md if your instructions carry it, this conversation, and the Agent Memory index. If they answer it, answer.
2. List the facts still missing. Tag each one:
   - the Human's own, or outside;
   - stable, or changing (needs a check now).
   Own and stable: knowledge search. Own and changing: calendar, Tracking Items, Routines, Slack, live mail, Drive, Notion, GitHub. Outside and stable: lev8, web background. Outside and changing: the web, checked now. [references/sources.md](references/sources.md) says what each source answers.
3. Search in rounds. First run the knowledge searches the personal knowledge policy calls for. When they return, decide whether the answer still needs anything else: a fact memory does not have, or a changing fact that memory gives only as a lead. If nothing, answer; do not query other sources just to be thorough. Otherwise query only the live or outside sources that settle those facts. Sources that are plainly needed from the start and independent of memory may run alongside the first round. A record of a past event does not by itself prove a changing present status. Where sources disagree, weigh recency and authority; do not assume that newer always means correct. If evidence remains insufficient, state the material uncertainty.
4. Anything memory gives that can change after it was recorded (a date or plan, where someone works or lives, their contact details, an amount, a deadline, whether something is done) is a lead. Before the answer states it as current, check the latest source that owns it (the calendar, recent mail or Slack, Tracking Items) once. If they disagree, use the latest and say what changed. Give a live-source query a window that covers the whole period asked about, and check date versus date-time boundaries so the end day is included.
5. When the answer chains facts held by different sources (a person found in memory, their current role or contact in recent mail, their time in the calendar), check each link in the source that owns it and for the right person and time. A link supported only by topical overlap is not established. Stop once the links are supported; if one cannot be established, say which.
6. Check the answer against what you are delivering:
   - a report: the answer first, key facts with where they came from, what was not checked;
   - a choice or recommendation: the candidates, the criteria, and the evidence for each;
   - a plan or schedule: the constraint list, the plan, and any conflict with the calendar or Tracking Items;
   - a draft or action: the draft and the facts it uses; nothing is sent, booked or bought without approval.
   Carry the constraint list into any later step or handed-off Task.
