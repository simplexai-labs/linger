# Taste

Xspace should feel like a quiet team tool. Agents are teammates, not spectacle.

## Refuse these defaults

- Purple-blue gradients, glass panels, or glowing dark-mode accents
- Giant metric cards, numbered section eyebrows, and identical icon-card grids
- Side-stripe callouts, sketchy illustrations, and wide ghost shadows on bordered cards
- Over-rounded cards (keep 8-16px product geometry)

## Keep these

- Light paper surfaces, compact navigation, and restrained apricot actions
- One accent used for commands and selection
- Specific copy that names the actual object and action
- Visual distinction through typography, spacing, and a small set of avatar colors, not extra chrome

## Audit pass

Before finishing a UI change, scan for decoration that does not carry information. Remove it. If two treatments compete, keep the one already used in Members, Chat, or Settings.
