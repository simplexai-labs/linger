# Memory Prompts

Prompt logic lives in `sync/`: execution prompts grouped by daily,
weekly, and client memory.

The TypeScript CLI only collects source material, invokes the configured LLM
Gateway directly with a prompt, validates JSON output, and applies returned
files. Summary, merge, sync, conflict, forgetting, and archive decisions belong
in these prompts.

All memory content is partitioned by memory subject key:

```text
<agent_management_id>/memory/me/
<agent_management_id>/memory/timeline/
<agent_management_id>/memory/knowledge/
```

Prompt outputs must use that subject key as the first path segment. Root-level
`updates/` is only for run artifacts generated by the CLI.

The prompt may return `memory_log_entries` to explain update intent. The apply
layer validates their subject keys and paths but does not store them.

Structure:

```text
prompts/
  sync/
    daily/
      daily.md
    weekly/
      weekly.md
    client-memory/
      client-memory.md
  tracking/
    tracking-items.md
  user-memory/
    update.md    # memory.md edits for the profile, daily and weekly cadences
  proactive/
    dreaming.md
```

LLM Wiki publishes the meeting and knowledge pages. Its stable document IDs are independent of the reader-facing paths.
